# Raw spatial data

Place downloaded, unmodified source datasets here temporarily on your own computer. This folder is intentionally ignored by Git, so files will not be pushed to GitHub.

For every dataset, record in `data/README.md`:
- dataset title and publisher;
- source URL and download date;
- licence / attribution requirements;
- CRS / EPSG code;
- fields used;
- known omissions, duplicates, or positional uncertainty.

Share data with teammates through an agreed file-sharing method or a small, appropriately licensed sample. Do not commit large datasets or restricted data.
